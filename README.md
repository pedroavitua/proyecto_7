# Análisis de anuncios de venta de vehículos

## Descripción del proyecto

El proyecto es una aplicación web interactiva para visualizar datos de ventas de carros en Estados Unidos que vienen de un histórico de datos.

La aplicación permite visualizar la distribución del kilometraje de los vehículos y analizar su relación con el precio de venta.

## Funcionalidades

- Visualización de una muestra del conjunto de datos.
- Histograma interactivo de la distribución del kilometraje.
- Diagrama de dispersión para analizar la relación entre kilometraje y precio.
- Casillas de selección para mostrar u ocultar los gráficos.

## Programas usados

- **Python:** lenguaje de programación.
- **Pandas:** procesamiento y análisis de datos.
- **Plotly:** creación de gráficos interactivos.
- **Streamlit:** desarrollo de la aplicación web.
- **Render:** alojamiento y despliegue de la aplicación.
- **Git y GitHub:** control de versiones.

## Estructura del proyecto

- `app.py`: código principal de la aplicación Streamlit.
- `vehicles_us.csv`: conjunto de datos de anuncios de vehículos.
- `notebooks/EDA.ipynb`: Jupyter NB de análisis exploratorio de datos.
- `requirements.txt`: dependencias de la aplicación.
- `README.md`: documentación del proyecto.

## Pasos para una ejecución local

1. Clonar el repositorio:

   `git clone https://github.com/pedroavitua/proyecto_7.git`

2. Acceder a la carpeta:

   `cd proyecto_7`

3. Instalar las dependencias del txt:

   `pip install -r requirements.txt`

4. Ejecutar la aplicación:

   `streamlit run app.py`
